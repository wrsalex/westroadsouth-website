# WestRoadSouth Artlist Style Kit

## How to Use in Artlist
1. Choose model: "Artlist Original 1.0" or "Flux"
2. Style preset: "Cinematic" or "Grit"
3. Upload reference image (generate once, reuse forever)
4. Append this to EVERY prompt:

```
Dark theme. Primary accent #E42869 (vibrant pink).
Secondary accent #FF9900 (warm orange). Deep navy/black
backgrounds (#0A0A0F). Clean, minimal, professional SaaS
aesthetic. Soft glow effects. No clutter. No photorealism —
abstract geometric and data-visualization style.
```
